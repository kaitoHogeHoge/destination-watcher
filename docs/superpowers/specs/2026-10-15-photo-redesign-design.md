# 都市の写真とカードのデザイン刷新（B 案：旅行誌風） 設計書

作成日：2026-10-15
元の設計書：`2026-10-13-destination-watcher-design.md`
見本：`site/mockup.html` の「B 旅行誌風」（作業の最後に削除する）

## 1. 目的

情報が増えた画面を、ひと目で分かり、旅行らしく見えるようにする。各都市のカードの上部に大きな写真を置き、大事な数字4つをタイルで見せ、詳しい情報は押して開く形にする。

### 成功の条件

- 4都市すべてに、その都市の写真（国旗や地図ではないもの）が出る
- 写真の撮影者・ライセンスが写真の上に小さく表示され、写真のページへ移動できる
- 写真が無い・読み込めないときは、落ち着いた色の帯になり、表示は崩れない
- カードを開かなくても、為替・来週の気温・安全・ベストシーズンが分かる
- スマホ幅（375px）で横にはみ出さない。明るい表示・暗い表示の両方で読める

## 2. 写真の取得（新しい部品 `photo`）

- `PhotoSource`：`name="photo"`、`provider="wikimedia"`、`label="写真"`、`refresh_days=90`
- 選び方（上から順に、最初に見つかったもの）：
  1. 設定ファイルの `photo`（任意。Wikimedia Commons のファイル名。例：`"File:Marina_Bay_at_night.jpg"`）
  2. 日本語版 Wikipedia の記事（記事名 = 行き先の `name`）の代表画像  
     `https://ja.wikipedia.org/api/rest_v1/page/summary/{name}` の `originalimage.source`
  3. 同じ記事の画像一覧の、最初の写真  
     `https://ja.wikipedia.org/api/rest_v1/page/media-list/{name}`
- 写真として使わないもの：ファイル名が `.svg`／`.png`／`.gif`、またはファイル名に `Flag_of`・`flag`・`Map`・`map`・`Locator`・`Coat_of_arms`・`Emblem`・`Seal_of`・`location` を含むもの
- 選んだファイルについて、Wikimedia Commons の API から次を取る  
  `https://commons.wikimedia.org/w/api.php?action=query&titles={ファイル名}&prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=960&format=json&formatversion=2`
  - `thumburl`（幅960px の画像）、`descriptionurl`（写真のページ）
  - `extmetadata.Artist`（HTML なので、タグを取り除いた文字にする。空なら「不明」）
  - `extmetadata.LicenseShortName`（例：`CC BY-SA 3.0`）
- 保存形：`{"url", "page", "artist", "license", "file"}`。見つからなければ `{"url": null}`（エラーにはしない）
- Wikimedia の利用ルールに合わせ、通信の User-Agent を `destination-watcher (https://github.com/kaitoHogeHoge/destination-watcher)` にする

## 3. カードの新しい形

```
┌──────────────────────────────┐
│ ［写真 230px・下に向かって暗く］  📷 撮影者 / ライセンス │
│  GB ・ イギリス                                       │
│  ロンドン（明朝体・大きく）                            │
│  現地 3:41 ・ 日本より−8時間                           │
├────────────┬────────────┤（写真に少し重ねる）
│ 💱 1 GBP      │ 🌤 来週の気温 │
│ 210.22円      │ 16° / 11°    │
│ 30日 +0.80%・平均的 │ 雨の日 2日 │
├────────────┼────────────┤
│ 🛡 安全       │ ★ ベストシーズン │
│ 情報なし       │ 6〜8月        │
│ お知らせ 3件   │ 今月 12.2°・79mm │
└────────────┴────────────┘
 ▸ 💱 為替レート              最終更新 10/15 11:25
 ▸ 🌤 天気予報（16日間）
 ▸ 🕐 これから12時間の天気
 ▸ 📅 月ごとの気候
 ▸ 🎌 祝日（今後6か月）
 ▸ 🛡 海外安全情報
```

### 3.1 写真の帯

- 高さ：パソコン 230px、スマホ 200px。写真は `cover` で切り抜く
- 下に向かって暗くするグラデーションを重ね、白い文字を読みやすくする
- 左下：国コード・国名（小さく字間を広く）、都市名（明朝体・大きく）、現地時刻と時差
- 右下：「📷 撮影者 / ライセンス」。押すと写真のページ（Commons）を開く
- 写真が無い・読み込めない：写真の代わりに落ち着いた色（ページの色より少し濃い色）の帯。文字はそのまま

### 3.2 要点のタイル（2×2）

| タイル | 大きな数字 | 下の小さな文字 |
|---|---|---|
| 💱 1 {通貨} | `210.22円` | `30日 +0.80% ・ 平均的`（円安は赤、円高は青） |
| 🌤 来週の気温 | `16° / 11°` | `雨の日 2日` |
| 🛡 安全 | `情報なし` または `レベル3`（危険レベルの色の文字） | `お知らせ 3件`。変化ありのときは `⚠ 変化あり` |
| ★ ベストシーズン | `6〜8月`（連続する月は「〜」でつなぐ。例：2・3・7月） | `今月 12.2° ・ 79mm` |

- 値の無いタイルは「—」、対象外は「対象外」
- 前回のデータ（取得失敗）のときは、小さな文字の先頭に ⚠ を付ける
- 中身は比較の一覧と同じ計算（`summarize`）を使う

### 3.3 詳しい情報

- 今の区切り（為替・天気予報・12時間の天気・気候・祝日・安全）を一覧の行として並べる。見出しにアイコンを付ける
- **初めて開いたときはすべて閉じておく**。開閉を一度でも操作したら、その状態を覚える（今の仕組み）
- 「写真」は区切りとしては表示しない（写真の帯に使う）

### 3.4 全体

- 配色：暖かみのある中間色（明るい表示：背景 `#f3f1ec`・カード白、暗い表示：背景 `#15171a`・カード `#1e2125`）。強調色・円安/円高の色は今のまま
- カード：角の丸み 22px、枠線なし、薄い影
- 比較の一覧：都市名の左に小さな丸い写真（28px）
- ページ上部の見出しと「最終実行」「すべて開く／閉じる」は今のまま、余白を整える

## 4. 設定ファイル

- `photo`（任意・文字列）を追加。値があれば Commons のファイル名として使う。README の表に追記する
- 設定の読み込みでは、`photo` があれば文字列であることを確かめる

## 5. テスト

- Python：写真の選び方（代表画像・国旗を飛ばす・画像一覧に回る・設定の指定を優先・見つからない）、撮影者の HTML を文字にする、保存形、設定の `photo` の型
- JavaScript：ベストシーズンの月の書き方（`6〜8月`、`2・3・7月`、`12・1・2月` は `12〜2月`）、タイルの中身の作り方（値なし・対象外・前回のデータ）
- 画面：4都市の写真と出典、写真が読み込めないとき、スマホ幅、暗い表示

## 6. やらないこと

- 写真の複数枚表示・スライド
- 写真の画像そのものの保存（Wikimedia の画像を直接表示する）
- 季節や時間帯で写真を変えること
